Appearance

Applied on top of the built-in theme, on every page, for every user of this workspace. Leave blank to use the built-in theme only. Applies immediately on save, no reload needed.

Extensions

A manifest-driven package contributing theme CSS, translation strings, and/or a custom tool. Applies to every user of this workspace. A manifest with tool_code runs real Python with full server privileges -- admin/owner only, with an explicit confirmation before install.

Install extension

Paste a manifest: {"name", "version", "author", "description", "theme_css", "strings": {"en": {...}, "ar": {...}}, "tool_code": "..."}. tool_code is optional and requires admin/owner + a risk confirmation.
